# 🌐 Sample Project: Landing Page BelajarGitApp

Folder ini berisi proyek website sederhana (HTML, CSS, JavaScript) yang disediakan khusus sebagai bahan latihan Anda.

## Ide Eksperimen Latihan:
1. **Latihan Branch & Edit**:
   - Buat branch baru: `git switch -c feat/tambah-kontak`
   - Tambahkan form kontak di `index.html`.
   - Commit dan merge ke `main`.
2. **Latihan Conflict**:
   - Edit baris judul di dua branch berbeda dan lakukan merge.
3. **Latihan Stash**:
   - Tulis perubahan setengah jalan di `app.js`, simpan dengan `git stash`, lalu kembalikan dengan `git stash pop`.
